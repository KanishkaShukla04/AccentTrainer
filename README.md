# AccentTrainer 🌍

An interactive web app that helps users learn US vs UK English words, pronunciation, and usage differences.

## 🚀 Features
- US vs UK word comparison
- Speech synthesis (accent playback)
- Smart dataset for learning
- Suggestion-based search
- Clean modern UI

## 🛠️ Tech Stack
- Next.js
- React
- Tailwind CSS

## 🎯 Goal
Help users understand real-world English variations between regions.

## ▶️ Run Locally
```bash
npm install
npm run dev
